# Q3W3 — Curriculum Guide Extract

Q3W3 Weekly preparation

Add administrator and teacher permissions

Starting point: Microsoft identity is validated; application roles are not yet enforced.

End-of-week check: Admin manages drafts; Teacher has only an authorized personal read path.

Explain these ideas before the build

Map validated tenant/object identity to a trusted server-side application role and Teacher record. Names, email text, browser storage, and user-submitted role fields are not sufficient authority. Deny unassigned users. Admin can manage catalog and draft meetings; Teacher cannot write or retrieve another teacher's data. Until publication is built, the Teacher view reports No published timetable yet rather than exposing drafts. Test the API directly because hidden UI controls do not enforce permission.

permission: An action a person is allowed to perform.

role: A named set of permissions.

deny: Refuse an action that is not allowed.

Prepare this week in order

1. Confirm the previous checkpoint works. Have one Admin, two Teacher test identities mapped to separate Teacher records, and one unassigned identity if available. Teacher controls assignments.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Build a small permission matrix before coding. Each row becomes an acceptance check.

4. Improve the prompt by focusing on this skill: Include forbidden cases in the prompt, not only successful cases.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
