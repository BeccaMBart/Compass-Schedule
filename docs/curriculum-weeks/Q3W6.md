# Q3W6 — Curriculum Guide Extract

Q3W6 Weekly preparation

Improve usability and add a shared test workflow

Starting point: Core authenticated draft, publication, and teacher workflows exist locally.

End-of-week check: Focused usability fixes and automated checks support reviewed changes.

Explain these ideas before the build

Usability and accessibility concern whether people can complete tasks clearly. Labels, keyboard access, visible focus, and useful errors matter. Treat a confusing message as a specific issue rather than requesting a redesign. A CI workflow runs checks in a defined environment; a green result proves only those checks. Keep secrets away from untrusted pull requests and run database tests against an isolated PostgreSQL service.

review: Checking a proposed change before accepting it.

bug: Behavior that differs from the intended result.

automation: A repeated task run by a tool.

Prepare this week in order

1. Confirm the previous checkpoint works. Prepare a short keyboard walkthrough and a GitHub pull request demonstration. Confirm the chosen Git host's CI capability; the reference workflow uses GitHub Actions.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Triage defects by impact: unauthorized access or wrong saved data before colors and spacing. Link each fix to a task and check.

4. Improve the prompt by focusing on this skill: Use observed user behavior as prompt evidence and constrain the patch to that issue.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
