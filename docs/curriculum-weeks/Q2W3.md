Build a room list and reusable component

Starting point: The React page has only a heading and purpose sentence.

End-of-week check: Two fictional rooms render through a RoomCard component.

Explain these ideas before the build

A component is a function that describes part of the UI. A prop supplies a value to that component. Rendering a list repeats a component using different data. IDs distinguish records; use them as stable React keys. The two-room array is visible temporary source data. It is not a database and should not be described as one. Build the list first, then improve reuse as a separate small change.

component: A reusable piece of a screen.

prop: Information passed into a component.

list: A collection of items shown together.
