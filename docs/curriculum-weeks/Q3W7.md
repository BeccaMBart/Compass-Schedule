# Q3W7 — Curriculum Guide Extract

Q3W7 Weekly preparation

Package the existing app for hosting

Starting point: The application works locally with separate development processes.

End-of-week check: A production container serves the built React UI and API, ready for deployment.

Explain these ideas before the build

Production packaging changes how the same application runs. Build React to static assets, serve them with FastAPI, and preserve /api routing. Avoid development reloaders on a host. A container needs a clear listening port, non-secret health endpoints, and server-only database settings. Development and production addresses differ: a host uses localhost; container-to-container requests use service names. A build is not evidence that hosted sign-in or database access works.

image: A packaged set of files and instructions for running software.

container: A running instance of an image.

configuration: Settings supplied for a particular environment.

Prepare this week in order

1. Confirm the previous checkpoint works. Verify Docker, current tests, and a local production test database. Have the Azure registry/resource choices ready for next week.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Freeze feature scope while packaging. Record the exact source commit and image tag for each release candidate.

4. Improve the prompt by focusing on this skill: Ask AI to adapt the current app for one target runtime, not generate a replacement application.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
