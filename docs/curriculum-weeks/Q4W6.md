# Q4W6 — Curriculum Guide Extract

Q4W6 Weekly preparation

Freeze scope and verify the release candidate

Starting point: Required repairs have been completed or remain explicit release blockers.

End-of-week check: A tagged release candidate satisfies every required feature and hosting check.

Explain these ideas before the build

A release candidate is a specific version, not a vague claim that the app is mostly done. A scope freeze protects time for verification. Traceability links each requirement to a real check and result. Azure must have its recorded teaching deployment evidence, and the permanent VPS must be currently available. Any missing required behavior remains a blocker; optional polish can wait.

release candidate: A version believed ready for final verification.

scope freeze: A decision to stop adding features.

traceability: Connecting a requirement to its task, change, and evidence.

Prepare this week in order

1. Confirm the previous checkpoint works. Prepare the complete requirement matrix, test data, image tag, migration revision, backup record, and Azure evidence. Keep the remaining two weeks available for blockers and handoff.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Freeze new features. Use the acceptance matrix as the remaining task list and tag the tested commit after checks pass.

4. Improve the prompt by focusing on this skill: Ask AI to audit evidence against requirements and explicitly mark missing or contradictory evidence.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
