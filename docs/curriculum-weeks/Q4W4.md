# Q4W4 — Curriculum Guide Extract

Q4W4 Weekly preparation

Run staff user acceptance tests

Starting point: Required workflows and both hosting milestones exist; remaining defects are tracked.

End-of-week check: Staff feedback is converted into reproducible, prioritized acceptance results.

Explain these ideas before the build

User acceptance tests follow real tasks, not a tour of buttons. An Admin must create and place a class; a Teacher must see only the approved relevant timetable. A confusing message is different from unauthorized editing or lost data. Record expected and actual results before choosing a fix. Required failures take priority over new ideas.

user acceptance: Checking whether real users can complete intended tasks.

severity: How strongly a problem affects use.

reproduction steps: Actions that make an issue happen again.

Prepare this week in order

1. Confirm the previous checkpoint works. Invite the teacher/aide or an available staff tester. Prepare fictional test records and the final acceptance matrix. The app is already deployed; do not replace the test with a prepared demo.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Use Must fix, Should fix, and Later categories. All required acceptance failures are Must fix, with owners and retest dates.

4. Improve the prompt by focusing on this skill: Give AI observed evidence and ask it to classify and narrow a problem before generating a solution.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
