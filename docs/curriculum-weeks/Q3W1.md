# Q3W1 — Curriculum Guide Extract

Q3W1 Weekly preparation

Make saves reliable and automate rule checks

Starting point: Sequential scheduling rules work; simultaneous edits remain unverified.

End-of-week check: Transactional writes and PostgreSQL tests protect scheduling integrity.

Explain these ideas before the build

Two requests can both see an empty slot before either saves. For this small single-term app, serialize scheduling-affecting changes by locking the existing active Term row at the start of a transaction. Then read fresh relevant data, validate, write, and commit. All paths that affect meetings, section teacher/limit, or room capacity must use the same boundary. Database foreign keys and useful uniqueness constraints provide additional protection. A failed operation rolls back. Students learn the one-at-a-time analogy; the teacher and AI implement the mechanism.

transaction: A group of changes that succeeds together or leaves the previous state.

regression: A previously working behavior that a change breaks.

evidence: An observed result supporting a claim.

Prepare this week in order

1. Confirm the previous checkpoint works. Create a separate PostgreSQL test database. Confirm tests cannot point at the working class database. Prepare two simultaneous booking cards.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Turn repeated manual checks into a small regression checklist. Mark pass, fail, or not run; never infer a pass.

4. Improve the prompt by focusing on this skill: Ask for a failing case first, then the smallest repair and a repeated check.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
