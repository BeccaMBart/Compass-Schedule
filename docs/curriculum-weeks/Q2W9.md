# Q2W9 — Curriculum Guide Extract

Q2W9 Weekly preparation

Add conflict rules and review the first product increment

Starting point: The local planner can save meetings but does not yet prevent collisions.

End-of-week check: Room, teacher, section, and capacity rules protect ordinary scheduling edits.

Explain these ideas before the build

For a fixed term/day/period, a room, teacher, or section must not be double-booked. A section seat limit must fit the selected room. Enforce these rules in the API before committing; UI warnings alone are insufficient. Check edits to rooms and sections as well as new meetings. A meeting moving to its own current slot must not conflict with itself. Concurrent requests need additional protection next week. This milestone proves sequential rules and records remaining limitations.

conflict: Two choices that cannot both be accepted.

rule: A condition a valid schedule must satisfy.

test: A check comparing expected and actual results.

Prepare this week in order

1. Confirm the previous checkpoint works. Use Section A taught by T1 with 24 seats, Section B taught by T2 with 18 seats, Room 101 capacity 24, and Art Studio capacity 18.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Define Done with one accepted and one rejected example. Review scope against the school-year deadline.

4. Improve the prompt by focusing on this skill: Give boundary cases and require explanation of why each should pass or fail.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
