# Q2W8 — Curriculum Guide Extract

Q2W8 Weekly preparation

Build manual timetable placement

Starting point: Rooms and catalog records exist; there are no meetings or planner.

End-of-week check: An administrator can place, move, and remove draft meetings using fixed day and period choices.

Explain these ideas before the build

Use one active term and a repeating Monday-to-Friday week with fixed periods P1, P2, and P3. A Meeting links section, room, day, and period; the teacher is derived from its section. An ordinary form and table are enough for manual scheduling. Avoid drag-and-drop and automatic scheduling. This week handles placement and input validity; conflict protection is the next required increment, so the draft is a local prototype and is not ready for staff use.

meeting: A section assigned a room and time.

draft: A working version still being edited.

acceptance check: An observable result used to judge a task.

Prepare this week in order

1. Confirm the previous checkpoint works. Prepare paper meeting cards and the standard fixture. The teacher selects one active term; no variable time ranges or multiple-year calendars are introduced.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Choose a minimum workflow: select, save, see, edit, remove. Break it into cards instead of asking for a complete scheduler.

4. Improve the prompt by focusing on this skill: Name non-goals and request one vertical slice from form to saved result.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
