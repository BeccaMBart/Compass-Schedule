# Q2W6 — Curriculum Guide Extract

Q2W6 Weekly preparation

Add persistent room storage

Starting point: React uses the temporary-memory API; a restart loses added rooms.

End-of-week check: Room data is stored in PostgreSQL and survives an API restart.

Explain these ideas before the build

PostgreSQL persists records independently of a running Python process. SQLModel maps models to database operations; a session groups interactions and commit saves an accepted write. A Docker volume retains database files. The local Python API connects to 127.0.0.1:5432; later containers will use service DNS instead. Do not keep a memory fallback after database conversion: an unavailable database must produce an honest failure. Repeated startup must preserve existing rows.

table: Records organized with the same fields.

row: One record in a table.

ID: A value identifying one record.

1. Confirm the previous checkpoint works. Verify Docker Desktop. Prepare the database-only Compose procedure and two-row drawing. Do not prepare application database code in advance.

3. Practice this project-management action with students: Record a dependency: database readiness blocks persistence tests. Define Done using a saved marker that survives restart.

4. Improve the prompt by focusing on this skill: Describe a migration from current behavior to new behavior, with preservation and failure requirements.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Create private local settings and start PostgreSQL

First verify the generated .gitignore excludes .env and preserves .env.example. Run this once from the repository root. It creates a private .env with a generated password without printing the password. If .env already exists, the command preserves it and stops; inspect that existing file privately instead of overwriting it.

python3.12 - <<'PY'
import os, secrets
password = secrets.token_hex(24)
lines = ["POSTGRES_USER=scheduler", "POSTGRES_DB=scheduler",
         "POSTGRES_PASSWORD=" + password,
         "DATABASE_URL=postgresql+psycopg://scheduler:" + password + "@127.0.0.1:5432/scheduler"]
fd = os.open(".env", os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
with os.fdopen(fd, "w") as f:
    f.write("\n".join(lines) + "\n")
PY
