# Q3W8 — Curriculum Guide Extract

Q3W8 Weekly preparation

Deploy the same application in Azure

Starting point: A tested production image exists; no Azure deployment has been completed.

End-of-week check: The authenticated application runs in Azure with managed PostgreSQL and verified HTTPS access.

Explain these ideas before the build

Use one Azure teaching environment: Linux App Service running the production container and Azure Database for PostgreSQL Flexible Server. Keep the database reachable through an approved private network path from the app and configure DNS correctly. Store credentials in server settings. Use the actual school subscription, region, and supported plan; do not infer government-cloud endpoints from unrelated work. The browser requires the actual HTTPS redirect URI registered with Microsoft. Deployment is complete only after hosted workflow checks.

host: A computer or service that runs an application.

HTTPS: A protected web connection.

cloud: Remote computing services reached over a network.

Prepare this week in order

1. Confirm the previous checkpoint works. School-approved Azure subscription, spending owner, registry, suitable App Service plan, network permissions, and PostgreSQL configuration must be available. Use the Azure steps printed in this week. Keep real credentials off the projector.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Track hosting dependencies and costs before deployment. The teacher owns spending and access; students maintain the checklist.

4. Improve the prompt by focusing on this skill: Supply verified target details and ask for exact environment-specific steps; never invent subscription IDs or prices.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
