# Q3W9 — Curriculum Guide Extract

Q3W9 Weekly preparation

Verify Azure recovery costs and the second milestone

Starting point: Azure runs the core product, but recovery and cost procedures need evidence.

End-of-week check: The Azure demonstration is documented, recoverable, and ready to inform VPS deployment.

Explain these ideas before the build

A backup file is not proof of recovery until restored to a separate target and checked. Use a supported PostgreSQL dump/restore process or verified managed recovery flow. Keep source backups separate from database backups. Cloud budgets notify; they do not automatically stop all spending. Stopping an app can leave plan, database, or storage charges. The class records an adult-owned schedule and cleanup plan while the permanent VPS work begins next quarter.

backup: A separate copy kept for recovery.

restore: Recovering data from a saved copy.

cost: Money required to operate a service.

Prepare this week in order

1. Confirm the previous checkpoint works. Have an approved separate restore target and access to cost/resource views. Do not restore over the working teaching database.

2. Prepare the fictional records or paper examples named above. Prepare account/tool access only; do not implement this week’s app changes before the live lesson.

3. Practice this project-management action with students: Review the milestone against required features and record operational risks with named adult owners.

4. Improve the prompt by focusing on this skill: Ask for an evidence-based runbook: exact action, expected result, failure response, and owner.

5. Keep the three lessons below in order. If a check fails, use that lesson’s repair prompt and preserve the working data. Record failed or not-run checks honestly.

Student record for the week

Each student keeps one note with their name/pseudonym, role, prediction, small change or review, observed result, and one concept in their own words. Use docs/student-work/ for class evidence. The teacher remains responsible for the application and all account credentials.
